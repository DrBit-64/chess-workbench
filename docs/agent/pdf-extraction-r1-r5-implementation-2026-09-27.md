# PDF 关系提取 R1–R5 实施与验收记录（2026-09-27）

本记录按 [R1–R5 计划](pdf-extraction-r1-r5-plan-2026-09-25.md)区分已实现功能、原页核对和未完成验收。页码均为 PDF 物理页。真实书页、请求、模型响应及 CCEF 留在 git 忽略的 `data/debug/` 与内容寻址存储；本文只记录简短棋步和证据身份，不复制棋书原文。中文残局书按操作者要求排除。

## 已实施的行为

- R1：旧事件编译器每次局部改挂后立即重算棋盘与后代状态；v8 的明确关系路径不进入旧的“最近合法位置”改挂链。Catalan p7 蓝色 `6...b6 7.cxd5` 的父关系在来源响应重放中正确；Magnus p139 的 `8...dxc4 9.Qxc4` 保持同一变化。
- R2：PDF 字符级颜色、粗体、位置随来源证据保存；词法候选保留原文偏移。无书名规则的阅读提示和模型推断角色在 `/sources/pdf-extractions/<run_id>/source` 显示，可跳回片段。图形棋盘字形不当正文棋步。
- R3：v8 模型输出 game、line、连续片段、root/continue/alternative_to/branch_after 和来源 ID；程序确定父节点、棋规和 CCEF。输入读连续页段及前后文，输出按完整变化群分批。独立例局按 `(game_ref, line_ref)` 隔离；跨块保留线路目录；连写记谱拆 token，重述不重复执行，暂不能判定的内容局部待审。只在发现非法关系根或短粗体正式谱行漏判时进行一次有界来源补问；程序修复使用保存响应重放。
- R4：审核页通过可见棋步与局面选择锚点；整段拖动和右键／点击选择共用改挂操作。预览由后端按新局面计算剩余问题数，支持跨序列分支迁移；撤销／恢复是不可变修订。带 `!` 的原书棋步使用已解析 SAN 预验；棋盘全局拖动处理不再取消棋谱拖动。
- R5 接线：资料页默认 `source_first`，后端创建 `pdf-extraction:v8` Job；来源页和审核页可直接从浏览器打开。正式知识库仍需人工批准，提取结果不会自动发布。
