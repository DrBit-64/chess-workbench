# ADR 0025：长篇编号开局理论沿用来源关系管线

- 日期：2026-10-02
- 状态：已实施；真实样本结果与边界见 `docs/agent/opening-theory-extraction-2026-10-02.md`
- 适用：同一个 PDF 独立提取及连续文档追加接口；不改变 Source → Knowledge → Repertoire → Exercise 的边界

2026-10-02 后续实测修正：真实多例局文档追加 288–318 暴露来源归属错误、依赖修复不完整和人工修订未继承。此前 Theory 内部追加试验不足以覆盖这一边界。调查和待实施补充方案见 [ADR 0026](0026-source-unit-scoped-incremental-review.md)；不能将本 ADR 的已实施状态理解为该真实场景已经通过验收。

## 观察与目标

Scandinavian 物理页 287–318 在同页从上一例局切换到 Theory，并依次展开 A–D、D1–D5、D41–D44、D51–D52。作者先列目录式选择，后重复编号正式讲解，还引用早先线路、描述相似但不相同的残局。这一段有 18 个不同编号标题。旧来源关系模型可以表达棋步父子边，但其按页数／候选棋步数划输出批次，未明确保留编号小节的状态。旧模式对 p287–290 的真实响应把预告中的 A2/A3 当成可播放分支，留下 5 个待审点。

目标是使长篇理论的全部正式小节有明确来源入口，跨批次和跨追加段能返回共同分支点。作者的目录层级是寻找入口的线索，不是棋步父子关系本身；编译器仍以明确来源引用和棋规为准。输出继续经过现有人工审核，不能直接进入个人开局库。

## 决定

1. 在来源文本上提取通用的“编号 + 棋步”标题候选，建立章节索引。重复编号的首次出现可作目录预告，后续同名标题作正文入口；相邻多个编号形成的目录在正文尚未到达时也保留为待展开小节。来源引用、页码和原文始终保留。它是提示，不能自动决定某棋步的父节点。
2. 对识别出多层编号的长章节，按正文小节优先组织有界输出窗口。目录预告作为只读阅读范围，不重复生成棋步。确实过长的小节再拆分；每批仍能读到完整选定范围及已解释结构。普通例局沿用原分组。
3. 模型仍使用 `chess-source-relations/1`，在已保存的来源关系输入中增加 `theory_sections` 和已经成功编译的 `theory_section_entries`。模型选择每个连续棋步片段的确切 `root`、`continue`、`alternative_to` 或 `branch_after`；程序只绑定所引用的来源棋步并验证棋规。兄弟小节返回同一个已知入口，不能接在前一兄弟小节末尾。相似局面与真正转置分开处理。
4. v9 追加沿用同一个解释与编译器。前驱与本次页段连续时，章节索引由二者合并构造；前驱原文仍只读。现有合法 `ContinuationAnchor` 目录保留同一前驱棋谱中的历史入口，并由保存的基线哈希约束。
5. `/pdf-extractions/{run_id}/source` 直接从已提交的来源片段构造同一索引，审核页面显示可折叠小节目录和正文标题棋步是否已入当前审核修订。没有新 SQL 表、任务种类或书名特判。

## 验收

- Scandinavian p287–318：全部 18 个编号正文标题需可定位；A/B/C/D、D1–D5、D41–D44、D51–D52 的入口按原书核对。p287 上半截断的上一例局应保持局部缺上下文，不能并到 Theory。预告标题不得重复入谱，p313 与 D43 的相似局面不得自动合并。
- 跨追加切点：此前只出现目录预告的编号在正文到达前保持待展开；后续可以从前段共同入口续接，而不要求用户重新输入 FEN 或节点 ID。
- Catalan p52–55 的 Game 10 与 Makogonov p65–70 的 Game 9 是此前未跑的新例局。`docs/evaluation/opening-theory-holdout-2026-10-02.json` 在真实回归调用前独立记录两局各 73 个合法主线半回合及关键支线入口。比对主线和父子关系，不以“提取出的棋步都合法”代替覆盖检查。
- 每次实测保存请求、模型响应、用量和编译候选于 gitignored 的 `data/debug/`。纯程序修改优先重放已存响应。自动化测试只使用固定响应，不调用付费 API。

## 当前范围

编号小节索引启发式只在足够长且出现多层编号时启用。目录只有一两项、排版损坏或跨越尚未读取页的前向引用，仍需要模型判断和人工审核。此次不建立作者格式配置、通用语法学习系统或自动个人开局库发布。
