# ADR 0028 个人实战棋谱与局面收藏

2026-11-07 · Accepted

## 棋谱与出处

「我的对局」拥有独立的实战档案。导入时复用有序 PGN 解析与标准棋局面图，保存选中对局的原始 PGN、头信息及每个节点的完整 FEN、主变关系、来源评注和 NAG。课程导入仍然按课程组织。一张棋盘图可以被两盘棋共用，各盘走到这里的路径、原文和个人判断分别保留。

平台及对局编号能确定唯一来源。对局链接、PGN 和账号同步遇到同一来源时使用已有记录。无可靠编号时，双方和主线相同只提示可能重复，由用户选择打开已有棋谱还是另存。账号同步只读取已结束的公开标准对局，记录进度和已处理的来源编号。导入结果与评语持久化在提供网页的同一工作站。

## 棋步与收藏

棋步评语属于这一盘、这一条路径上的着法。收藏以一个确定的棋谱节点为出处，每个出处可添加标题、评语和标签。收藏棋盘默认关联刚走完的棋步，从某着菜单收藏走前局面则明确关联将要走的这步。一个位置可以记录多个直接相关的着法。全文匹配使用这些关联和收藏本身的文字，避免同盘其它着法混入结果。

「回到收藏处」按棋谱与节点打开原谱。「查其他出现」按共享 Position 查询全部已收录棋谱，默认限实战主线，可选择包含分析变例。完整状态与着法次序保存在每个出处，以便区分重复局面及回合计数。

## 生命周期

取消星标隐藏条目，再次收藏原处可恢复笔记和标签。用户也可以永久删除收藏。归档棋谱保留其深链接，可从已归档列表恢复或永久删除。数据库外键只清理该棋谱拥有的记录，保留其他棋谱以及共享局面与着法。版本号保护不同设备上的修改。

练习通过手选收藏创建，独立保存用户的问题与合法答案变化，支持多个可接受的走法。保存时由后端按该出处的完整 FEN 验证。删除练习保留原收藏；永久删除其出处则清理练习。引擎续弈沿用工作台现有的 Stockfish 对弈接口。
