# ChessWorkbench project description

ChessWorkbench is a single-user, local-first chess study workbench. It connects source material, positions, move paths and explanations, with human-reviewed publication into courses. Its internal chess model is a position graph; PGN is an exchange format.

The available product is course editing and learning, local engine analysis, and v8/v9 PDF extraction with review and publication. The PDF path was accepted for personal use on 2026-10-01; broad cross-book evaluation remains deferred.

The next product direction is being chosen from actual study needs. Chessbook.com may supply the opening tree; the workbench can focus on notes around plans, pawn breaks and move-order conditions. Personal repertoire, spaced repetition, game sync, video and collaboration are not current commitments.
